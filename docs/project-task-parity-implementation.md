# Projectタスクの共通UI・所有者割り当て

## 実装

- ProjectとPrivateの共有タスクを同じTaskScreen／TaskItem／TaskDetailView／TaskMemoFields／タグ選択・移動部品で表示。日付・時間帯、ドラッグ表示と自動スクロール、複数選択、完了・アーカイブ・復元・消去を共通化。
- 所有者はassigneeUserIdを使用。新規は作成者、未割り当てはnull。旧データの項目未設定時だけ在籍中の作成者に補完。作成履歴のownerUserId／creatorUserIdは割り当て変更で移譲しない。
- 所有者のPrivateだけに共有タスクを表示。Projectの全在籍メンバー（viewerを含む）がタスクを編集・割り当て可能。ToDoと一般のProjectメモの権限は維持。
- startAt／elapsedMinutesで共有計測。Firestoreトランザクションで最新状態から開始・中断・完了・アーカイブ・消去を計算し、別タスクは停止しない。
- フォームは変更した項目だけ保存。所有者とタスクの購読をアカウント・Project切替で破棄し、在籍状況の変更も所有者表示へ反映。
- タスク本文と関連Projectメモを原子的に保存。sourceTaskIdとrelatedMemoIdの相互確認に限定して他メンバーの編集を許可し、一般メモの所有権は変更しない。旧メモは関連を検証して更新時に紐付けを補完。消去時は関連メモも非表示にする。
- 退出処理は最新タスクをトランザクションで確認して割り当てを解除し、対象の共有計測を停止。
