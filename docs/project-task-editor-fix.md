# Projectタスク編集・上部配置の修正

## 変更内容

- 一覧ヘッダーはuseSafeAreaInsetsの上端をそのまま使用。誤って16px引く配置を除去し、一覧開始位置も同じ上端＋ヘッダー40pxに統一。
- 編集ヘッダーは左右の操作領域と中央タイトルを分離し、長いProject名は1行に省略。「完了」「キャンセル」は高さ44px・幅64px以上、追加のhitSlopを持つ。
- タスク名が空欄のときは「完了」の色とアクセシビリティ状態を無効にし、保存できない理由を表示。
- 入力値は同期的な参照にも保持し、Reactの次の描画前に保存しても最新のタスク名・メモ・所有者・配置・新規タスク状態を使用。
- 保存と状態更新は同期ロックで二重実行を防止。保存中の終了を防ぎ、成功時だけ閉じる。失敗時は画面上にも理由を表示し、下書きと再試行を維持。終了済みセッションの遅い保存結果から別の画面を閉じない。
- 編集フォーム全体の毎秒更新を削除し、進行中の計測表示だけをProjectTaskTimingで更新。未開始・中断・完了時にはタイマーを動かさない。

## 端末での確認

1. Projectタスク一覧の日付、カレンダー、アーカイブ、選択ボタンが上部で欠けないこと。
2. 新規タスク名を入力し、キーボードを表示したまま右上の「完了」を1回タップして保存・終了できること。
3. 既存タスク名・メモ・所有者を変更して保存できること。完了直前に入力した文字も保存されること。
4. 保存失敗時は理由が表示され、入力が残り、再試行できること。
5. 編集画面で停止・クラッシュが再発しないこと。計測中も入力・選択・保存が操作できること。

クラッシュログは取得できておらず、ネイティブクラッシュの原因は未確定。今回是正したコード上の問題と、端末での解消確認は区別する。

本番Rules・Functions・データ構造は変更せず、デプロイとSimulator／実機の起動は行っていない。既存の共有権限・所有者割り当て・本文保存方式を維持。
